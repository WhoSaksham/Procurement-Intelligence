# Ask the evidence on a real LLM — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the prepared-answer matcher behind `POST /v1/ask` with a LangGraph pipeline on Gemini that retrieves passages, drafts cited claims, verifies them, keeps conversation threads, uses the open package as context, and falls back to prepared answers whenever the model is unavailable.

**Architecture:** Everything lives in `services/api/src/modules/ask`. Pure pieces (retrieval, package passage, claim checks, limits) are separate files with their own tests. The model sits behind a small `AskModel` port: the real adapter wraps `ChatGoogleGenerativeAI.withStructuredOutput(zod)`; tests use scripted fakes; e2e uses a deterministic fake selected by a request header that only works in E2E mode. A LangGraph `StateGraph` wires the nodes; model nodes catch their own errors and route to a `prepared` node. The service around the graph handles limits, threads (Mongo `askThreads`) and LangSmith tracing. The web Ask page becomes a conversation.

**Tech Stack:** Express 5, Mongoose 9, zod 4, Vitest; `@langchain/langgraph` 1.7.5, `@langchain/core` 1.5.0, `@langchain/google-genai` 2.3.7, `langsmith` 0.13.1; Next.js 16 + TanStack Query; Playwright.

**Spec:** [docs/superpowers/specs/2026-11-21-ask-llm-design.md](../specs/2026-11-21-ask-llm-design.md)

## Global Constraints

- Pin exact versions: `@langchain/langgraph@1.7.5`, `@langchain/core@1.5.0`, `@langchain/google-genai@2.3.7`, `langsmith@0.13.1`.
- `GEMINI_MODEL` default `gemini-3.5-flash-lite`; `ASK_RPM` default 5; `ASK_DAILY_LIMIT` default 100; `LANGSMITH_PROJECT` default `procurement-ask`. All optional; none fail closed in production.
- `supportMin` stays the seeded 0.75. At most 6 claims, each ≤ 300 chars. Retrieve top 8 passages. History: last 4 turns, question + kept claim texts only. 20 turns per thread; TTL 30 days on `updatedAt`.
- Time: 8 s per model call, 20 s per run; web proxy timeout for `v1/ask*` 30 s; catch-all route `maxDuration = 60`. 60 s cool-down after a Gemini 429.
- Temperature 0 on every call.
- Tests, CI and e2e never reach Gemini. The fake model is reachable only when `config.allowSimulateDown` (env `E2E`) is true and the request carries `x-ask-model: fake`.
- Existing behaviour that must not change: injection regex returns exactly `{ blocked: true }` plus an echoed `threadId` when one was sent; `GET /v1/ask/questions` unchanged.
- **Commits:** the user's standing rule is no commit without explicit approval, one approval per commit, no AI attribution lines. Work on branch `feat/ask-llm`; do **not** commit per task. One commit at the end, after asking.

## Review Focus

1. A model reply that cites ids it was not given, or cites nothing, must never appear as a kept claim (Task 3 tests).
2. A follow-up ("and for Uganda?") while Gemini is failing must still find a prepared answer (Task 5 test `fallback matches on previous question + follow-up`).
3. A run that overruns the 20 s budget must return prepared mode, not a 5xx (Task 5 test with a hanging fake + short budget).
4. A package name containing instruction-like text must reach the model only inside the `pkg` passage, never the system prompt (Task 4 prompt test).
5. Reloading `?t=` after the package was edited must show the citation text the claim was verified against (Task 7 route test + Task 9 e2e).

### Task 4: The model port, Gemini adapter, prompts and the fake

**Files:**
- Create: `services/api/src/modules/ask/model-port.ts`, `prompts.ts`, `gemini.ts`, `fake-model.ts`, `services/api/test/ask-prompts.test.ts`

**Interfaces:**
- Produces (`model-port.ts`):
  ```ts
  export interface HistoryTurn { q: string; kept: string[] }
  export interface AskModel {
    name: string;
    contextualise(i: { history: HistoryTurn[]; q: string }, signal: AbortSignal): Promise<{ standalone: string; inScope: boolean }>;
    draft(i: { q: string; passages: Passage[] }, signal: AbortSignal): Promise<{ outOfScope: boolean; claims: Draft[] }>;
    verify(i: { claims: { i: number; text: string; passages: Passage[] }[] }, signal: AbortSignal): Promise<{ scores: { i: number; support: number }[] }>;
  }
  export class ModelError extends Error { constructor(readonly kind: 'quota' | 'timeout' | 'invalid' | 'upstream', cause?: unknown) }
  ```
- `prompts.ts`: `contextualiseMessages`, `draftMessages`, `verifyMessages` returning LangChain `BaseMessage[]`; exported zod output schemas `ContextualiseOut`, `DraftOut` (claims max 6, text max 300), `VerifyOut` (support 0..1).

- `fake-model.ts`: `fakeModel(): AskModel` deterministic: contextualise → `standalone = history.at(-1)?.q + ' — ' + q` (or `q`), `inScope = !/\b(recipe|weather|poem|joke)\b/i`; draft → for each of the first 2 passages a claim = the passage's quote sentence citing it, plus `"Every package in the cohort finished early."` citing the first passage (so one claim is removed), `outOfScope` false; verify → 0.95 if the claim text occurs in a cited passage's text, else 0.2.

**Interfaces:**
- Consumes: Tasks 2–4.
- Produces: `runAsk(i: { q: string; history: HistoryTurn[]; pkg: Passage | null; sources: Passage[]; answers: Answer[]; supportMin: number; model: AskModel | null; unavailable?: 'not configured' | 'limit' | 'cooldown'; budgetMs?: number /* default 20_000 */; callbacks?: Callbacks }): Promise<RunResult>` where
  `RunResult = { mode: 'llm' | 'prepared'; model?: string; notice?: string; outOfScope?: true; standalone: string; claims: KeptClaim[]; steps: Step[]; failure?: ModelError['kind'] }`.
- Graph: `StateGraph` with `Annotation.Root` (steps reducer = concat). Nodes `contextualise` (skipped when `history` empty), `retrieve`, `draft`, `verify`, `prepared`. Conditional edges: `model == null || unavailable` → `prepared`; any node with `failure` set → `prepared`; `outOfScope` → END. Each node appends one Step with real counts and elapsed ms. `invoke(state, { signal: AbortSignal.timeout(budgetMs), callbacks })`.
- Prepared node matches on `standalone` if contextualise produced one, else `history.at(-1).q + ' ' + q`. Notices: no model → `'Live model not configured — showing a prepared answer.'`; any other → `'Live model unavailable — showing a prepared answer.'`.
